# Deprecated Python Backend

This directory contains the legacy FastAPI backend code for reference. It is no longer part of the active project architecture and is preserved strictly for rollback and reference purposes.

### Archived Files
- `main.py`: Stateless FastAPI server that performed system probes via `psutil` and `GPUtil`.
- `requirements.txt`: Python package dependencies catalog.

All new backend services are developed inside `/backend-laravel` using PHP, Laravel, and MySQL.
